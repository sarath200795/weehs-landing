How this is enforced

This console is the record of what each account is meant to have. It stores that record in this browser and can export it as JSON. It does not, by itself, stop anyone opening an app — each WE EHS app has to read the same record and enforce it server-side. Export the JSON and feed it to that API when the backend is ready.
